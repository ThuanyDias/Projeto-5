## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de criar uma aplicação simples de sorteio de números, aplicando conceitos de lógica com JavaScript e organização de layout moderno com CSS.

O foco principal foi praticar validação de dados, manipulação do DOM e centralização utilizando Flexbox.

---

## 🚀 Funcionalidades

✔ Geração de número aleatório dentro de um intervalo definido pelo usuário  
✔ Validação de campos vazios  
✔ Verificação se o valor mínimo é menor que o máximo  
✔ Inclusão correta do valor máximo no sorteio  
✔ Interface moderna e centralizada  

---

## 🧠 Habilidades Desenvolvidas

### ⚙️ JavaScript
- Geração de números aleatórios com `Math.random()`
- Manipulação do DOM
- Captura de valores inseridos pelo usuário
- Validação de dados (`isNaN`)
- Estruturas condicionais (`if`)
- Controle de fluxo com `return`
- Eventos com `addEventListener`

### 🎨 CSS3
- Centralização vertical e horizontal com Flexbox
- `align-items`
- `justify-content`
- `flex-direction`
- `min-height: 100vh`
- Controle de transparência com `opacity`
- Personalização de cores com `rgba()`
- Customização de inputs

### 📄 HTML5
- Estruturação semântica
- Criação de inputs numéricos
- Organização de elementos
